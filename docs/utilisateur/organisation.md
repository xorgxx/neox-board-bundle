# Organiser les cartes et les éléments

[← Index du guide utilisateur](README.md)

## Déplacer une carte

Dans la Vue d’ensemble, saisissez la poignée à points à gauche du titre de l’espace. Les cartes et colonnes acceptant le dépôt sont mises en évidence. Déposez la carte avant ou après une autre carte, ou dans une colonne vide. Les deux colonnes sont indépendantes ; le déplacement ne mélange pas les séquences de cartes entre elles. L’ordre et l’affectation à la colonne sont sauvegardés.

Au clavier, focalisez la poignée puis utilisez **Alt + ↑ / ↓** pour réordonner dans la colonne et **Alt + ← / →** pour déplacer vers l’autre colonne.

## Réordonner liens et sections

Faites glisser une ligne de lien ou de section vers sa nouvelle position dans la carte. Les éléments suivent leur ordre d’insertion par défaut et le nouvel ordre est sauvegardé. Le dépôt d’un lien sur un séparateur le place dans cette section. Déplacer une section vers un autre espace emporte son groupe de liens jusqu’au prochain séparateur.

Au clavier, focalisez l’élément puis utilisez **Alt + ↑ / ↓**. Les contrôles de glisser-déposer peuvent dépendre du navigateur et du type d’appareil ; dans ce cas, utilisez le clavier ou les commandes de formulaire.

## Ajouter une adresse depuis le navigateur

Faites glisser l’URL depuis la barre d’adresse et déposez-la sur la carte cible. Vérifiez le titre et l’adresse dans l’aperçu, puis choisissez **Ajouter**. Si l’adresse existe déjà dans l’espace ou si elle ne peut pas être validée, l’ajout est bloqué. Le contrôle s’effectue sur l’espace cible, ce qui permet d’ajouter le même site dans deux espaces différents.
