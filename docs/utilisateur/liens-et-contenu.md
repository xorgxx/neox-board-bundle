# Liens, sections et widgets

[← Index du guide utilisateur](README.md)

## Ajouter un raccourci

Dans l’en-tête de l’espace, choisissez **Ajouter un lien**. Indiquez un titre et une adresse, puis enregistrez. Pour une adresse Web, saisissez le domaine et le chemin ; le formulaire gère le protocole HTTP ou HTTPS. Lorsqu’une favicon peut être récupérée, elle s’affiche à côté du raccourci. Sinon, une initiale colorée sert de repère.

Vous pouvez également glisser une adresse depuis la barre d’adresse du navigateur vers une carte. Un aperçu du titre et de l’adresse apparaît. Neox vérifie le lien et les doublons avant d’activer **Ajouter**. Une adresse déjà présente dans l’espace ne peut pas être ajoutée une seconde fois.

## Actions sur un lien

- Cliquez sur le titre pour ouvrir le site dans un nouvel onglet.
- Utilisez le crayon pour modifier le titre ou l’adresse.
- Utilisez l’étoile pour ajouter ou retirer le lien des Favoris.
- Utilisez la corbeille pour le supprimer après confirmation.

Les ouvertures effectuées depuis le dashboard sont prises en compte par le filtre de date de la recherche. Une adresse interne de navigateur est traitée à part : voir [Pages internes du navigateur](pages-navigateur.md).

## Créer des sections

Choisissez **Section** dans l’en-tête d’un espace, donnez-lui un nom et enregistrez. Une section est un séparateur visuel entre les éléments du menu. Faites glisser un lien sur la section pour le placer dans son groupe. Le déplacement d’une section vers un autre espace déplace également les liens de son groupe jusqu’à la section suivante.

Les sections peuvent être renommées ou supprimées avec leurs commandes dans la carte. Leur position suit l’ordre des éléments.

## Widgets

Le bouton **Widget** permet d’ajouter un widget si votre installation en fournit les types. Le formulaire comporte un titre, un identifiant de type, une configuration JSON et l’option **Activé**. Le type et la configuration dépendent des extensions installées ; le bundle ne garantit pas qu’un type arbitraire possède un rendu dans chaque installation.
