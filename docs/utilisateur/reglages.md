# Réglages et personnalisation

[← Index du guide utilisateur](README.md)

Ouvrez **Réglages** depuis la barre latérale.

## Apparence

- Le bouton de thème bascule entre le mode clair et le mode sombre. Ce choix est conservé dans le navigateur.
- **Couleur du thème** propose six accents : violet, bleu, cyan, émeraude, rose et ambre. Le choix est mémorisé dans le navigateur utilisé.
- Dans **Arrière-plan du dashboard**, choisissez le thème actuel, une couleur unie ou une image. Les formats acceptés sont JPEG, PNG et WebP, jusqu’à 5 Mo. Vous pouvez sélectionner une nouvelle image ou supprimer l’image enregistrée.

## Localisation météo

Saisissez une ville, éventuellement suivie du pays, par exemple `Lyon, France`, puis choisissez **Mettre à jour**. Une ville reconnue remplace la localisation par défaut pour votre tableau. La météo et les informations de calendrier disponibles sont ensuite calculées pour cette localisation. Si la ville n’est pas reconnue, essayez avec son pays.

La météo présente aujourd’hui et les quatre jours suivants. Les indications de saint, jours fériés et vacances scolaires dépendent des données disponibles pour la date, le pays et la zone scolaire.

## Rechercher les favicons manquantes

Dans Réglages, choisissez **Rechercher les favicons manquants**. Neox tente de récupérer l’icône des raccourcis qui n’en ont pas encore. Les liens qui possèdent déjà une favicon sont ignorés. Si aucune icône n’est trouvée, l’initiale colorée du lien reste visible.

## Arrière-plan non conservé

Les préférences de couleur du thème et le mode clair/sombre sont stockés localement dans le navigateur. Ils ne suivent donc pas automatiquement le compte sur un autre appareil ou dans un autre navigateur. La localisation, l’arrière-plan et les éléments du tableau sont enregistrés sur le tableau de l’utilisateur.
