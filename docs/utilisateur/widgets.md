# Gérer les widgets

[← Index du guide utilisateur](README.md)

Ouvrez **Widgets** dans la barre latérale pour choisir quelles cartes apparaissent sur la Vue d’ensemble. Chaque widget peut être activé ou désactivé séparément. Son état est enregistré avec votre tableau.

## Widget météo

Le widget **Météo** affiche les prévisions de votre localisation pour aujourd’hui et les quatre jours suivants. Activez-le depuis la page Widgets ; la carte apparaît sur la Vue d’ensemble. Désactivez-le depuis la même page pour retirer cette carte du tableau.

Dans **Disposition**, choisissez une largeur d’une ou de deux colonnes, une colonne gauche ou droite et un emplacement avant ou après les espaces. En mode deux colonnes, le choix gauche/droite n’a pas d’effet. Vous pouvez aussi saisir la poignée à points du widget et le déposer dans la colonne gauche ou droite ; il passe alors en largeur une colonne.

La localisation affichée est celle définie dans [Réglages → Localisation météo](reglages.md). Le résumé météo présent dans la barre supérieure reste indépendant de cette carte.

La page Widgets accueillera les prochains widgets disponibles. Une commande de gestion apparaît pour chaque widget proposé par l’installation.

Après la mise à jour, appliquez la migration `Version20261110222000` dans l’application hôte pour enregistrer l’état et la disposition du widget.
